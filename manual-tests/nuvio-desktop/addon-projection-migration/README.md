# Sanitised Nuvio Desktop Addon Projection Migration Round Trip

## Why this exists

Issue [#37](https://github.com/davecollections/tmdb-id-lookup/issues/37) provides automated migration proof. Owner-reviewed private Ultra MAX and AIO Metadata import/export pairs established the evidence contract without placing private configuration data in this repository.

This checkpoint verifies that the exact JSON generated by the production importer → migration → serializer path is accepted and normalized by Nuvio Desktop. The repository artifact is sanitised and contains no private configuration URL.

## Files

- `builder-migrated-input.json`: the generated Stage A input for Nuvio Desktop.
- `generation-report.json`: deterministic provenance, counts, validation status, and the input SHA-256.
- `nuvio-desktop-export.json`: the later Stage B output; do not add this file until it is exported by the project owner.

Regenerate Stage A with:

```powershell
node scripts/generate-migration-round-trip.mjs
```

Check the committed artifacts without changing them with:

```powershell
node scripts/generate-migration-round-trip.mjs --check
```

## Expected generated structure

- One collection and three folders.
- One movie source, one series source, and one anime source, in that order.
- Three matching compatibility projections in the same order.
- No-genre values exported as `null`.
- The real `"Action"` genre retained.
- Unknown projection metadata retained.
- Only sanitised `https://example.invalid/` artwork.

## Important expectation

The synthetic addon identity may not resolve catalog content. That is acceptable for this checkpoint.

The test covers collection import acceptance; folder, source, and projection preservation; order preservation; export normalization; and unknown-field preservation where Nuvio Desktop supports it. It does not claim catalog playback or live addon resolution.

## Owner instructions

1. Back up or export your current Nuvio collections before testing.
2. Record the Nuvio Desktop version and build.
3. Import `manual-tests/nuvio-desktop/addon-projection-migration/builder-migrated-input.json`.
4. Confirm the test collection appears.
5. Confirm it contains three folders in this order: movie, series, anime.
6. Do not edit or reorder anything.
7. It is acceptable if the synthetic addon reports unavailable or not found.
8. Immediately export the collections from Nuvio Desktop.
9. Save the exported file as `nuvio-desktop-export.json`.
10. Return the exported JSON file, Nuvio Desktop version/build, operating system, whether import succeeded, any visible error or warning, and whether all three folders were present and ordered correctly.

After exporting, remove the temporary test collection using Nuvio's collection-removal control if your client provides one. The exact client label is intentionally not assumed here.

## Stage B acceptance checks

The returned export will be checked for:

- one matching collection;
- three folders;
- three authoritative sources;
- three projections;
- preserved order;
- movie, series, and anime types;
- `null`, `"Action"`, `null` genre values;
- provider/addon identity;
- the projection sentinel;
- presentation fields;
- Nuvio-added explicit null/default fields;
- any client-specific normalization or dropped fields.
